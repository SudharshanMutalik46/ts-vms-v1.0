PATCH: App.xaml.cs
==================

Add these service registrations near the other service registrations:

services.AddSingleton<Services.PlaybackManifestService>();
services.AddSingleton<Services.PlaybackEngineService>();

Add this view model registration near the other view model registrations:

services.AddTransient<PlaybackViewModel>();

Why:
- PlaybackViewModel must be resolvable from MainViewModel.NavigateToPlayback()
- PlaybackEngineService should be long-lived for the current desktop session
