# Phase 4.7: Recording Control APIs

## Architecture
- **Public API (`vms-control`, 8080):** Handles JWT auth, RBAC, DB persistence (Schedules), and Export generation. 
- **Internal API (`vms-recording`, 8082):** Handles in-memory state changes (Start/Stop/Pause/Resume, Reload Schedules). Protected by `X-Service-Key`.

## Manual Overrides vs. Scheduler
When a user calls `/api/v1/recording/cameras/{id}/start`, `vms-recording` registers a `ManualOverride = true` for that camera. 
- Overrides bypass the `ScheduleEngine`.
- Overrides **DO NOT** bypass the `LicenseGate`.
- Calling `/stop` removes the override and returns the camera to its baseline scheduled state.

## Export Engine
The Export API `POST /api/v1/recording/exports` triggers a background job that:
1. Queries Phase 4.5 `recording_segments` for chunks matching the time range.
2. Copies the files to `/exports/recordings/<uuid>/`.
3. (In 4.8) Stitches them via FFmpeg. Returns a ZIP/MP4 download URL.
